## 摘要
代码生成通常在程序的原始空间中进行训练：模型生成一个候选解决方案，并接收稀疏的执行反馈，通常只是一个通过/失败的二值结果。测试时扩展（test-time scaling）通过对推理过程进行多样采样并进行比较评估来丰富推理，但这一过程中揭示的比较信息在推理后被丢弃。我们认为，这些信息定义了一个双重评判空间（dual judgment space），它提供了更加丰富的训练信号：模型不再仅从孤立的成功或失败中学习，而是从自身合理尝试的相对正确性结构中学习，识别哪些成功、哪些失败，以及它们之间的区别。我们提出了 DuST（Dual Self-Training，双重自训练）框架，用于从双重评判空间进行自训练。DuST 从模型自身分布中采样候选程序，通过沙盒执行给它们打标签，保留包含成功和失败的分组，并使用 GRPO 训练模型根据执行正确性来对候选程序进行排序。该目标纯粹是判别性的：模型从未因生成正确程序而直接获得奖励。双重自训练同时改进了评判与生成能力。在跨越两个模型家族、三个模型规模（4B 到 30B）的五个模型中，DuST 在 LiveCodeBench 的 Best-of-4 测试时扩展中表现出持续的改进。对于 LiveCodeBench v6 上的 Qwen3-30B-Thinking 模型，评判质量提升了 +6.2 NDCG，单样本 pass@1 提升了 +3.1，Best-of-4 准确率提升了 +4.1。训练后的模型单次输出的性能可匹配基础模型的 Best-of-4 表现。在相同排序数据上的 SFT 仅提升评判而未提升生成，验证了基于策略的强化学习是将双重空间学习传递回原始生成的有效机制。

## Abstract
Code generation is typically trained in the primal space of programs: a model produces a candidate solution and receives sparse execution feedback, often a single pass/fail bit. Test-time scaling enriches the inference procedure by sampling multiple candidates and judging among them, but the comparative information this process reveals is discarded after inference. We argue that this information defines a dual judgment space that provides a far richer training signal: the model learns not from an isolated success or failure, but from the relative correctness structure across its own plausible attempts, identifying which succeed, which fail, and what distinguishes them. We introduce DuST (Dual Self-Training), a framework for self-training from the dual judgment space. DuST samples candidate programs from the model's own distribution, labels them through sandbox execution, retains groups containing both successes and failures, and trains the model to rank candidates by execution correctness using GRPO. The objective is purely discriminative: the model is never directly rewarded for generating correct programs. Dual self-training improves both judgment and generation. Across five models spanning two families and three scales (4B to 30B), DuST consistently improves Best-of-4 test-time scaling on LiveCodeBench. For Qwen3-30B-Thinking on LiveCodeBench v6, judgment quality improves by +6.2 NDCG, single-sample pass@1 improves by +3.1, and Best-of-4 accuracy improves by +4.1. The trained model's single rollout matches the base model's Best-of-4 performance. SFT on the same ranking data improves judgment without improving generation, confirming that on-policy RL is the mechanism that transfers dual-space learning back into primal generation.

## 一、研究问题与背景

- **研究动机**：当前代码生成模型通常在“原始生成空间（primal space）”中训练，即模型根据问题生成程序并依据执行结果（通过 / 失败）获得稀疏反馈。这种训练信号过于简单，无法反映模型内部多样可行解之间的相对正确性结构。  
- **现有现象**：测试时扩展（Test-time Scaling, TTS）通过在推理时采样多个候选并使用“评判者（judge）”选择最优方案，可提升推理性能，但这种比较信息通常在推理结束后被丢弃，未被用于进一步训练。  
- **核心问题**：如何将测试时评判的相对正确结构转化为模型的训练信号，从而让模型学会“理解什么是正确”，并将此判别知识反哺生成过程。  
- **研究目标**：提出一种机制，使模型不仅在执行结果层面学习成功与失败，还能从自身生成的多个候选方案间的比较中获得更密集、更结构化的监督信号。

## 二、方法论：DuST 框架

### 1. 核心思想
- **双空间概念**：
  - **原始空间（Primal Generation Space）**：模型直接生成代码并接受二值执行反馈。
  - **双重评判空间（Dual Judgment Space）**：围绕生成的多个候选程序形成比较与排序任务，模型学习区分正确与错误的候选。  
- **核心假设**：在双重评判空间中训练模型区分正确与错误代码，能学习到更细粒度的可执行正确性特征，这些特征会转移到原始生成性能上。

### 2. 技术流程
1. **采样候选代码**：模型从自身分布中采样一组候选程序。  
2. **执行与标注**：在沙盒环境运行这些程序，获得二值正确性标签。  
3. **分组筛选**：保留包含至少一个正确与一个错误样本的混合组，以确保排名对比可用。  
4. **构造训练数据集**：每个训练样本包含问题、代码集合和执行标签。  
5. **定义排名奖励（Ranking Reward）**：  
   - 模型对候选组输出排序结果。  
   - 奖励函数统计模型是否将正确代码排在错误代码之前。  
   - 格式错误的输出会被惩罚。  
6. **强化学习优化**：采用 **Group Relative Policy Optimization (GRPO)**，执行 on-policy 训练，使模型在评判空间优化后，参数同样用于生成空间。  
   - **核心区别**：相比监督式排序（SFT），GRPO 的 on-policy 机制允许学习信号通过策略更新影响生成行为。  
   - **目标函数**包括剪切比和 KL 正则项以稳定训练。

### 3. 算法流程（文字说明）
```
输入：问题 x
1. 采样候选代码集合 C = {c1,…,cK}
2. 执行获得标签 y = {y1,…,yK}, yi ∈ {0,1}
3. 构造混合组并定义执行奖励 Reexec(ρ; y)
   = 平均判断正确代码排在错误代码之前的比例
4. 使用 GRPO：从当前策略采样多个判断响应 o_i
   计算相对优势 A_i = (r_i - 均值) / 标准差
5. 更新策略 πθ 以最大化 A_i，经剪切与 KL 惩罚。
输出：更新后的模型参数 θ，用于生成与评判两者。
```

## 摘要
奖励模型（Reward Models，RMs）已成为语言模型（Language Models，LMs）后训练过程中不可或缺的组成部分，支持策略对齐与测试阶段扩展。然而，奖励模型在代码生成领域的研究相对较少，现有工作主要集中在执行反馈上。这一取向使后训练过程仅限于针对可独立运行的代码优化功能正确性。在本研究中，我们探讨多语言、多标准代码奖励模型的训练与评估。为此，我们首先构建了 Themis-CodeRewardBench，这是一项用于评估代码奖励模型的基准测试，涵盖五个偏好维度（即标准）与八种编程语言，并在此基准上对 50 多种代码、数学及通用奖励模型进行了分析。通过观察当前奖励模型在功能正确性之外的评分能力有限，我们进一步开发了 Themis-CodePreference，这是迄今为止最大的开源代码偏好数据集（超过 35 万个偏好对）。在此基础上，我们训练了 Themis-RM——一套用于灵活多标准评分的多语言代码奖励模型，参数规模从 6 亿至 320 亿不等。实验与消融研究表明，该模型展现出良好的扩展趋势、多样偏好训练下的强跨语言迁移能力，以及多标准训练对于可靠代码奖励建模的重要性。

## Abstract
Reward models (RMs) have become an indispensable fixture of the language model (LM) post-training playbook, enabling policy alignment and test-time scaling. Research on the application of RMs in code generation, however, has been comparatively sparse, with existing work largely focusing on execution feedback. This choice constrains post-training to optimizing functional correctness over self-contained executable code. In this work, we examine the training and evaluation of multilingual, multi-criteria code RMs. To this end, we first compile Themis-CodeRewardBench, a benchmark to evaluate code RMs across five preference dimensions (i.e., criteria) and eight programming languages, on which we profile 50+ code, math, and general-purpose RMs. Observing the limited proficiency of current RMs beyond scoring for functional correctness, we develop Themis-CodePreference, the largest open-source collection of code preferences to date (more than 350k preference pairs), and use it to train Themis-RM, a suite of multilingual code reward models for flexible multi-criteria scoring, ranging in size from 600M to 32B parameters. Our experiments and ablations demonstrate positive scaling trends, strong cross-lingual transfer when training on diverse preferences, and the importance of multi-criteria training for reliable code reward modeling.

- **研究背景**：  
  奖励模型（Reward Models, RMs）是现代大模型（LM）后训练中用于对齐用户偏好的关键环节，在对话、推理等领域已被广泛应用。然而，**代码生成领域的奖励建模仍主要依赖运行时执行反馈**（例如单元测试正确性），这种方式只能评估*功能正确性*，忽视了代码的非功能质量维度（如可读性、效率、安全性等）。

- **核心问题**：  
  作者指出，现有代码奖励信号存在三大问题：
  1. **局限性**：仅限于可独立执行的代码；
  2. **偏狭性**：无法反映非功能指标；
  3. **语言单一性**：多数研究仅关注 Python 等高资源语言。  
  因此，该研究旨在**训练可同时处理多语言、多维度代码质量标准的奖励模型**，以实现*灵活的多准则评分与跨语言泛化*。

## 二、方法论与技术框架

### 1. 总体思路
作者提出了 **Themis 框架**，涵盖：
- **基准数据集构建（Themis-CodeRewardBench）**
- **大规模偏好数据集构建（Themis-CodePreference）**
- **奖励模型训练体系（Themis-RM）**

核心目标是打造一个**可在多标准、多语言、多任务上鲁棒运作的代码奖励模型**。

### 2. 方法结构
#### （1）数据阶段
- **Benchmark**：Themis-CodeRewardBench  
  - 由13个子数据集组成，共 **约8.9k 条偏好样本**；
  - 涵盖 **5个评价维度**：  
    - Functional Correctness（功能正确性）  
    - Execution Efficiency（执行效率）  
    - Memory Efficiency（内存效率）  
    - Readability & Maintainability（可读性与可维护性）  
    - Security Hardness（安全性）
  - 覆盖 **8种编程语言**（C、C++、C#、Go、Java、JavaScript、Python、Ruby）。

- **训练数据集**：  
  - **Themis-GeneralPreference**：11万+ 通用偏好样本（涉及人类偏好与检索任务）  
  - **Themis-CodePreference**：35万+ 代码偏好对，覆盖上述5个评价维度。

#### （2）模型与训练机制
- 模型基座：**Qwen3 系列（0.6B–32B 参数）**
- 采用两阶段训练：
  1. **Preference Model Pre-Training (PT)**：先在通用偏好数据上训练，使模型具备一般人类偏好评估能力；
  2. **Preference Modeling (PM)**：在多语言代码偏好数据上继续训练以专注代码质量评分。
- **训练目标函数（基于 Bradley-Terry 模型）**：
  \[
  L = -E[ \log\sigma(r_\theta(y_c)-r_\theta(y_r)) + \lambda \log p_\theta(y_c) + \mu \cdot (r_\theta(y_c)+r_\theta(y_r))^2 ]
  \]
  - 其中 \(r_\theta\) 为奖励得分，\(\lambda,\mu\) 为正则项系数；
  - 附加**条件语言建模损失**与**奖励幅度正则化**以防过拟合。
- **输入设计**：通过系统提示 (system prompts) 明确标准（如“根据内存效率评分”），保证不同维度之间的可分辨性。

## 六、主要结论与发现

1. **性能显著提升**：  
   Themis-RM 系列在所有五个维度上超越主流 RMs，最大模型（32B）在综合准确率达 **91.82%**。

2. **功能正确性之外的优势**：  
   相较于基于测试执行的 RM，Themis-RM 能稳定评估非功能性标准（效率、安全、可读性等）。

3. **正向规模效应**：  
   模型规模越大，评分一致性与对抗鲁棒性越强，符合常见的 scaling law 趋势。

4. **跨语言迁移性强**：  
   单语言（Python/Java）训练的模型可在未知语言上保持高精度，表现出明显的知识迁移。

5. **多维编码标准互补**：  
   多标准联合训练优于单标准甚至模型合并，表明多个维度之间存在正迁移。

6. **下游能力验证**：  
   在代码重排序和对抗任务中，Themis-RM 的鲁棒性明显优于其他模型，能有效抵御“奖励操控”行为。

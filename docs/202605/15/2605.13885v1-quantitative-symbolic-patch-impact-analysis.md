## 摘要
传统的等价性检查将程序分类为等价或非等价，但在补丁影响分析等任务中，这种分类提供的信息不足，因为预期打过补丁的程序版本与原始程序应当是不等价的。当两个程序版本不等价时，确定它们在什么条件下出现差异以及受影响的输入比例仍是一个开放的挑战。在本研究中，我们提出定量符号部分等价性分析（quantitative partial equivalence analysis），这是一种通过量化原始（存在漏洞的）代码与修补后代码之间行为差异来评估软件补丁的方法。通过符号分析，我们识别出在何种输入条件下修补后的程序与原始程序表现出相同或不同的行为。我们的方法进一步细化了非等价性分析，通过测量输入域中行为分歧的程度来刻画差异。为了在数值域上进行高效的定量分析，我们提出基于区间搜索的启发式算法，为等价性提供可靠的下界。我们在来自广泛使用的开源项目（Linux、Qemu、FFmpeg）的90个CVE补丁上验证了该方法，同时还在一个基于Juliet测试集的数据集中评估了包含CWE的程序。结果表明，定量部分等价性分析能够有效刻画并量化补丁影响。此外，在EqBench基准上的实验发现了5对被误标记为等价的C程序，我们进一步识别了它们行为分歧的输入条件。

## Abstract
Traditional equivalence checking classifies programs as equivalent or non-equivalent, providing insufficient information for tasks like patch impact analysis where it is expected the patched version of the program to be non-equivalent to the original program. When two program versions are non-equivalent, determining under what conditions they differ and what percentage of inputs are affected remains an open challenge. In this work, we introduce quantitative partial equivalence analysis, an approach for assessing software patches by quantifying behavioral differences between the original (vulnerable) code and the patched code. Using symbolic analysis, we identify input conditions under which patched and original programs exhibit identical or divergent behaviors. Our approach refines non-equivalence by measuring the extent of behavioral divergence across the input domain. For efficient quantitative analysis of numerical domains, we propose a range-based search heuristic that provides a sound lower bound on equivalence. We demonstrate our approach on 90 CVE patches from widely used open-source projects (Linux, Qemu, FFmpeg), as well as on a Juliet Test Suite-based dataset containing programs with CWEs. Our results show that quantitative partial equivalence analysis effectively characterizes and quantifies patch impact. Additionally, experiments on the EqBench benchmark reveal five C program pairs that are mislabeled as equivalent, and we identify the input conditions under which their behaviors diverge.

- **核心问题**：传统的程序等价性分析仅判断两个程序是否完全等价或不等价，这在补丁分析场景下难以提供实用信息。因为补丁后的程序理应与漏洞版本不完全等价，更关键的是要知道在何种输入条件下两者行为不同，以及差异影响的输入比例。

- **研究目标**：提出一种能定量评估补丁影响的新方法——**定量符号部分等价性分析（Quantitative Symbolic Partial Equivalence Analysis）**，用于刻画两个程序版本间的行为差异范围与条件。

## 二、方法论与技术要点  

### 1. 核心思想  
- **部分等价性定义**：两个程序在输入空间的部分子集上输出相同即视为部分等价，在剩余输入集上非等价。  
- **量化目标**：通过符号执行与公式推理，计算出输入域中等价与不等价的比例（即补丁影响面）。  
- **关键概念**：  
  - *等价集* \(D_{eq}\)：输入使两个程序输出一致。  
  - *非等价集* \(D_{neq}\)：输入导致行为分歧。  
  - *补丁影响面*：两版本程序的非等价输入集合 \(D_{neq}\)。  

### 2. 技术路线  
- **符号执行扩展总结**：使用扩展符号执行生成包含输入及输出约束的符号摘要（Symbolic Summary），以公式形式表示程序路径与行为。  
- **分类算法 EqChecker**：  
  - 判断等价条件、总非等价、部分等价三类情况；若 S1⇔S2 不可满足则为部分等价。  
- **区间搜索启发式算法**：  
  - 提出三种范围搜索策略，均基于数值输入域划分并调用 SMT 求解器判断程序在局部区间内是否等价：  
    1. **Relational Range Search**（多参数同时划分）——可捕捉参数间关系，但复杂度高。  
    2. **Iterative Range Search**（单参数迭代划分）——更可扩展，计算复杂度线性。  
    3. **Iterative Priority Range Search**（优先向零值靠近划分）——假设行为在小数值区间更稳定，降低求解次数。  
    4. **Combined Range Search**——综合以上两种方案，对每个输入维度选取最佳下界。  
- **定量计算公式**：  
  - 等价比例：\(|D_{eq}| / |D_I| × 100%\)。  
  - 搜索算法记录下每个区间的最小最大值，根据区间长度累加生成等价域的下界。  
- **基线比较方法**：  
  - 枚举模型计数（Enumerative Model Counting）  
  - 基于输出投影与模型计数的公式化推理（使用 SearchMC、Ganak、ABC、qCoral 计数器）。

## 八、不足与局限  

- **符号执行依赖性**：算法依托差分符号执行生成摘要，若符号执行受路径爆炸或复杂语句限制，分析将失败。  
- **适用范围**：当前方法仅支持数值型输入域，尚未扩展到字符串或复杂结构域。  
- **关系捕捉局限**：迭代搜索方法无法识别多参数间的复杂关系；仅在 Relational 模式下才能描述。  
- **计算代价与深度限制**：区间递归深度需手动设定（LIMIT=8 或4），对结果上下界有影响。  
- **外部有效性风险**：实验程序规模较小（平均 8–64 LOC），尚未验证在大型工业系统上的性能。

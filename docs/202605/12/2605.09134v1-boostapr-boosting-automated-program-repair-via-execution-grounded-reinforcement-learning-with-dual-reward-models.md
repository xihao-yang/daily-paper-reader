## 摘要
基于强化学习的程序自动修复受限于稀疏的执行反馈与粗粒度的序列级奖励，这使得难以判断哪些编辑真正修复了漏洞。我们提出了 BoostAPR，这是一个三阶段框架，用于应对这些挑战：（1）在带有推理轨迹的、经执行验证的示例上进行监督微调；（2）基于执行结果训练双奖励模型——一个序列级评估器和一个行级信用分配器；（3）在 PPO 优化过程中，行级模型将奖励重新分配给关键编辑区域。该行级信用分配在中等粒度上运作，自然契合代码修改的特点。在 SWE-Gym 上训练并在四个基准上评估后，BoostAPR 在 SWE-bench Verified 上取得了 40.7% 的成绩（比基础模型提升 22.9 个百分点），在 Defects4J（Python 到 Java 迁移）上达到 24.8%，在 HumanEval-Java 上达到 84.5%，在 QuixBugs 上达到 95.0%，在开源模型中展现出具有竞争力的结果和强大的跨语言泛化能力。

## Abstract
Reinforcement learning for program repair is hindered by sparse execution feedback and coarse sequence-level rewards that obscure which edits actually fix bugs. We present BoostAPR, a three-stage framework addressing these challenges: (1) supervised fine-tuning on execution-verified demonstrations with reasoning traces, (2) training dual reward models--a sequence-level assessor and a line-level credit allocator--from execution outcomes, and (3) PPO optimization where the line-level model redistributes rewards to critical edit regions. This line-level credit assignment operates at an intermediate granularity naturally suited to code changes. Trained on SWE-Gym and evaluated on four benchmarks, BoostAPR achieves 40.7% on SWE-bench Verified (+22.9pp over base model), 24.8% on Defects4J (Python-to-Java transfer), 84.5% on HumanEval-Java, and 95.0% on QuixBugs, achieving competitive results among open-source models with strong cross-language generalization.

## 一、研究背景与核心问题

- **研究动机**：自动化程序修复（Automated Program Repair, APR）旨在减少软件维护与调试的高昂人力成本。  
- **核心问题**：传统利用大语言模型（LLMs）的程序修复仍存在三大挑战：  
  1. **执行反馈稀疏**：模型仅能获得“是否通过全部测试”的二值信号，无法判断部分正确的修复。  
  2. **奖励粒度过粗**：强化学习中通常在序列级分配奖励，难以确定哪些具体代码编辑起到了修复作用，造成高梯度方差与训练效率低。  
  3. **分布偏移问题**：训练集与实际仓库中的漏洞差异大，模型在真实场景中泛化能力受限。  

- **研究目标**：提出一种能从执行反馈中学习、并在细粒度层面分配奖励的强化学习框架，从而提高程序修复的准确性与泛化能力。

## 二、方法论：BoostAPR 框架

BoostAPR 是一个**三阶段**的执行反馈驱动强化学习系统，核心思想是结合**监督学习、双奖励模型**和**策略优化**，进行分层奖励分配与自适应学习。

### 1. 三阶段训练流程

1. **阶段 I：执行验证的监督微调（Execution-Verified SFT）**
   - 在 SWE-Gym 平台上生成包含“推理轨迹 + 修复补丁”的高质量数据。
   - 使用通过全部测试的示例进行微调，过滤掉不通过的样例（约 35% 通过率）。
   - 目标函数为标准的下一 token 预测损失：
     \[
     L_{\text{SFT}} = -E_{(x,y)} \sum_t \log \pi_\theta(y_t|x,y_{<t})
     \]
   - 此阶段将教师模型的诊断推理过程“迁移”到学生模型。

2. **阶段 II：双奖励模型训练（Dual Reward Learning）**
   - 基于执行结果训练两类奖励模型：
     - **Rseq**：序列级评估器，预测整体补丁质量；
     - **Rline**：行级信用分配器，识别关键编辑区域。
   - 奖励目标融合**回归 + 偏好学习**混合损失，用于校准绝对分数与相对排序。
   - 信号来源包括：补丁应用成功率、测试通过率与编辑成本惩罚。

3. **阶段 III：带双奖励的 PPO 强化学习**
   - 使用 Rseq 获取序列奖励，再由 Rline 将奖励重分配至关键编辑行，实现 token 级奖励塑形。
   - 算法流程（简化）：
     ```
     1. 使用已训练的 π₀ 采样候选补丁；
     2. 计算执行评价 r*；
     3. 用 Rseq 预测整体质量分数；
     4. 用 Rline 分配行级权重映射回 token；
     5. 结合 PPO 更新策略参数（包含 KL 约束）。
     ```
   - 使用 **LoRA 低秩适配**实现参数高效更新。

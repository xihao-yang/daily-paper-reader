## 摘要
近期关于大型语言模型（LLMs）的研究强调了扩展推理计算的重要性。从这一视角出发，提出了最先进的方法 Scattered Forest Search（SFS），其结合了精心设计的初始种子与文本优化，用于多轮代码纠正。然而，该方法的复杂性使得推理性能提升的关键因素不够明晰。为了解决这一问题，我们分析了 SFS，并提出了一种更简洁的方法——Iterative Refinement of Textual Directions（IRTD），该方法固定初始代码并迭代优化文本方向。由于 IRTD 的简洁性，我们通过 Oracle-Guided Inductive Synthesis（OGIS）在理论上确立了 IRTD 的安全性。在多个代码生成基准测试上的实验表明，IRTD 的推理性能与当前最先进的方法相当。这些结果表明，即使没有复杂的搜索结构，仅通过高质量文本方向对初始代码进行优化，也可以有效提升推理性能。

## Abstract
Recent work on large language models (LLMs) has emphasized the importance of scaling inference compute. From this perspective, the state-of-the-art method Scattered Forest Search (SFS) has been proposed, employing Monte Carlo Tree Search with carefully crafted initial seeds and textual optimization for multi-turn code correction. However, its complexity makes it unclear what factors contribute to improvements in inference performance. To address this problem, we analyze SFS and propose a simpler method, Iterative Refinement of Textual Directions (IRTD), which fixes initial codes and iteratively refines textual directions. Because of the simplicity of IRTD, we theoretically establish the safety of IRTD using Oracle-Guided Inductive Synthesis (OGIS). Experiments on several code generation benchmarks suggest that IRTD achieves inference performance comparable to state-of-the-art methods. These results indicate that, even without complex search structures, refining initial codes with high-quality textual directions alone can effectively improve inference performance.

## 二、方法论：IRTD（Iterative Refinement of Textual Directions）

### 1. 核心思想

- **核心概念：**  
  固定初始代码，将改进过程聚焦于“文本方向（textual directions）”的生成与优化；
  
- **要点区别：**
  - 不像 SFS 那样反复重建搜索树；
  - IRTD 始终在相同的初始代码上进行**“文本指令”迭代修正**；
  - 通过逐轮反馈“文本方向 → 修正版 → 反馈 → 下一轮方向”，渐进改进代码。

### 2. 算法流程（文字描述）

1. **初始生成：**  
   模型首先根据提示 `p` 生成若干初始代码 `c₁...cₙ`。
2. **文本方向生成：**  
   针对每个初始代码，模型生成多个文本方向 `d₁...dₘ`，这些方向代表改进建议。
3. **代码改进与反馈：**  
   根据选中的方向 `ds`，模型生成修正版代码 `cr`；然后依据验证测试集评价修正结果。
4. **共享信息更新：**  
   将验证结果反馈为共享信息 `I`，在下一轮文本方向生成时用作上下文，以指导更有效的后续修正。
5. **迭代终止条件：**  
   若通过所有验证测试或达到最大迭代次数 `imax`，则停止。

### 3. 理论分析：安全性证明

- 基于 **Oracle-Guided Inductive Synthesis (OGIS)** 框架，论文证明 IRTD 满足三项“安全”性质：
  1. **版本空间单调收缩（V_{t+1} ⊆ V_t）**；
  2. **正确解不被消除（包含真实可行方向）**；
  3. **搜索空间非空**；
- 理论定理表明 IRTD 在概率条件下不会丢失真实解，并能在有限步内收敛至满足安全条件的代码修复。

- 对比：线性自我修复（Linear Self-Refine）方法由于每轮更新代码本身，可能导致版本空间空化，从而“丢失”正确方向。

## 六、主要结论与发现

1. **广度探索更重要：**  
   从理论与实验均发现，在多轮代码修复中，“向不同文本方向扩散”比深度递归修正更有效。
2. **复杂结构非必要：**  
   仅靠固定初始代码与高质量文本方向迭代即可获得 SFS 级性能。
3. **IRTD 理论安全：**  
   通过 OGIS 框架验证其搜索空间稳定、无遗漏真实解。
4. **性能结果：**  
   在 HumanEval、MBPP、APPS 上，IRTD 的 Pass@k 达到或略高于 SFS，同时显著简化推理结构。
5. **多初始代码增强区分性：**  
   理论与实验证明更多初始代码可提升区分力与多样性，但会引入假设削弱的权衡（安全性与判别性的 trade-off）。
